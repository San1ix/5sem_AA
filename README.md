# Лабораторная работа №1
## Задание 
Написать "Испытательный стенд" для практического сравнения 4-х алгоритмов поиска: 
    
 - линейный поиск
 - бинарный нерекурсивный поиск обычный
 - бинарный нерекурсивный поиск улучшенный
 - бинарный рекурсивный поиск

___
Чек-поинты:
1. Программа предоставляет консольное меню, где пользователь может ввести N - кол-во различных элементов в массиве и сам массив, искомое число и выбрать метод поиска.
2. Для бинарного поиска массив надо сортировать.

3. Два набора функций: 

    - простые алгоритмы (для схем-алгоритмов и prodaction): принимает N, массив и искомое число. Возвращает только индекс;
    - расширенные алгоритмы (для отчета и таблиц): то же, что и простые, только дополнительно еще что-то считают.

___

Инструкция по взаимодействию с программкой:
1) Для начала, естесна, собрать ее и запустить
```bash
mkdir build
cd build
cmake ..
make
./lab1
```
2) Развлекайтесь))
---

*Маленькие примечания:*
- в коде используется два массива: исходный и отсортированный исходный;
- массив можно задать лапками, либо отдать на откуп программе(генерация);
- бинарный нерекурсивный вариант А классический;
- бинарный нерекурсивный вариант Б выполнен с отложенной проверкой, где убрано ветвление внутри циклы, платим за это лучшим случаем,
зато худший и средний дают результаты лучше классического.
